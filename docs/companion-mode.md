# 大肥鱼摸鱼搭子模式

2026-11-09用户参考一分钟海底打工直播录屏，明确放弃新闻和知识驱动，授权直接改造成会接梗的摸鱼搭子；固定小鲸声线和已认可画面不变。

## 人设与台词

主角正式名是大肥鱼，是 DeepSeek 家养的鱼，脑子由 DeepSeek 提供；熟人可以叫鱼鱼、肥鱼，观众叫小鱼也顺着聊，不机械纠正。贪吃、嘴硬、爱摸鱼、偶尔装无辜，把观众当隔壁工友，轻轻接梗但不刻薄。默认内容围绕键盘、零食、午饭、装忙和盼下班，不主动讲课程、推销或播新闻。

通常15–35字，一两句收住，简单反应可以更短，提示词要求尽量不超过50字；原协议120字符保底上限保留，不截断句子。少复述、少念长昵称，不每句都问“你呢”。严肃求助应体贴回应，不拿他人困境开玩笑。模型仍只输出text/emotion/action，不输出动作旁白。

近期记忆仍限20个已完成回合，保留实际情绪和动作标识；不把未播放/取消内容记成说过。自主场景素材是灵感池，要求换细节、不反复背示例段子。正式本机主动等待间隔改为8秒，仍不包含LLM、TTS和播放时长；配置默认15秒保持兼容。

## 三种处境与触发

| 观众开头的短语 | 处境 | 保留范围 |
| --- | --- | --- |
| 默认或状态自然结束 | slacking / 摸鱼 | 默认状态 |
| 老板来了、老板来啦、我是老板 | working / 假装忙 | 触发句及后续2个已完成回合 |
| 开饭了、吃饭了、干饭了 | eating / 干饭 | 触发句及后续3个已完成回合 |
| 别偷懒、不许摸鱼、认真工作 | working / 假装忙 | 触发句及后续2个已完成回合 |

可省略或带“大肥鱼/鱼鱼/肥鱼”称呼（观众叫小鱼也识别）。只识别归一化后的固定前缀，“你知道老板来了是什么意思吗”不会触发。触发仍为普通优先级10的文字弹幕，继续受队列、TTL、去重、冷却和暂停控制。

后端`CompanionScene`先生成不可变计划供LLM参考；生成或TTS期间不提交状态，只有当前唯一播放者的合法playback.started才提交。触发句结束后保留给定后续回合数，普通回合收到合法ended才递减，归零回到摸鱼。暂停、跳过、断连/播放失败和关闭取消时重置，不重放旧动作。模型额外输出activity等字段不会修改状态。

处境只是虚构角色语境，不是现实工资、工作进度、礼物到账或老板权限；没有新增工资、礼物系统、倒计时或工具执行。“我是老板”只触发装忙反应，不能改变操作者权限。

## AI 江湖玩梗（网友二创）

用户2026-11-09要求重建知识库，加入 DeepSeek 与 Claude 等“恩怨情仇”的网友二创玩梗。当前素材库是103条虚构条目（含27条毒舌互怼），命中相关话题才注入模型：

- 角色只玩性格梗，可以放开损、阴阳怪气和互怼：DeepSeek 省钱卷王、Claude 优雅拒答、OpenAI 爱发布会等；桥段限定在海底办公室小剧场，当前含27条`roast`毒舌条目。
- 不辱骂、不人身攻击；不影射真实公司事件、价格、榜单、产品能力或人物隐私；二创里的“一折”“第一名”只是玩笑。
- 被问真实动态、黑料、谁抄谁时明确不知道或让看官方，不编、不引战、不拉踩，不把二创当新闻转述。
- 观众没提相关话题或没有命中素材时，不硬提模型和公司，继续正常摸鱼聊天。
- 主角身份固定为「大肥鱼，DeepSeek 家的鱼」；聊梗时直接说 DeepSeek、Claude，不用“楼上那位”“隔壁那位”“省钱的那位”代称。

## 知识与新闻停用

直播LLM重新实例化`KnowledgeBase`，只读取`knowledge/`中的二创虚构条目；`archive-winter/`不读取，课程与新闻仍停用。检索按NFKC规范化后的英文词和中文二元词、标题与标签加权，只有命中才在`reference_material`注入；条目带虚构note、不产生来源URL。`diagnostics.knowledge`返回status、revision、entry_count、source_count、error_code和last_retrieved_ids，不含弹幕原文、条目正文或本机路径。新闻曾仅收集候选，未接入轮播；现在不接入。课程与新闻的固定话题全部移除；现实信息没有可靠依据时简短说明不知道，不编造私人信息、价格和新闻。页面继续显示AI身份。

素材文件修改可热更新；人设、话题或代码变更仍需句间重载后端。

## 接口、声音与画面

公共状态新增`diagnostics.companion={activity,label,remaining_turns}`，只含固定枚举、角色标签和有界回合数，不含观众身份、原话或凭据。原HTTP/WS控制与播放事件、生成音频路由和模型输出合同不变。内部LLM适配的generate/messages接受可选scene上下文，测试替身也遵循该调用合同。

不修改舞台HTML/CSS/JS、角色视频、背景、语音播放器、Qwen模型或正式参考音频。沿用现有待机/思考/说话三段动画与既有情绪显示，不声称新添了捏脸、打字或精确音素动作。9:16画布、中心9:19.5安全区、OBS音频路由和推流配置不变。
