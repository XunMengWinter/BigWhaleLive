## 阶段 1A 自动化与本地演示

测试注入单调时钟、可控随机源和 LLM/TTS 替身，避免真实等待数十秒。用可控挂起请求覆盖取消竞态，不以仅检查函数返回值代替状态与事件验证。离线用例拦截并拒绝任何外部网络请求。

| ID | 操作或条件 | 通过条件 |
| --- | --- | --- |
| A01 | 默认配置启动，打开舞台与控制台 | paused、idle；无外部请求；明确显示演示 LLM、语音关闭、演示角色 |
| A02 | running、播放者就绪、队列为空，推进时钟 | 自主间隔之前无发言；到时恰有一条 ready；started/ended 后才完成一轮 |
| A03 | 发送合法模拟弹幕 | 返回 202；reply 关联正确输入；字幕显示一次；完成计数与记忆只写一次 |
| A04 | 同 client_message_id 同内容重试；随后复用 ID 改内容 | 前者 200 duplicate，不重复入队；后者 409 id_conflict |
| A05 | 同用户在冷却内换 ID 发言；队列填满后换用户发送 | 分别 429 user_cooldown、queue_full；拒绝项不消耗去重或冷却 |
| A06 | 输入空白、超长、未知字段、阻止词、超限请求 | 分别按协议拒绝；不调用模型，不回显原始凭证或危险 HTML |
| A07 | 入队后推进到 TTL，再允许调度 | 过期项不回复，expired 增加，后续合法项仍可处理 |
| A08 | 当前正在播放时收到新弹幕 | 原音频不中断；新弹幕等待；无两段语音重叠 |
| A09 | 在 generating、synthesizing、awaiting_playback、playing 各阶段暂停 | mode=paused、队列清空、epoch 增加；注入迟到结果和确认均无新播放或记忆写入 |
| A10 | 暂停后恢复；连续重复 start/pause | 不重放取消项；幂等控制不创建第二个调度器；新消息可处理 |
| A11 | 有当前发言时 skip，再在无当前发言时 skip | 前者取消当前且保留队列；后者返回 409；旧回调不能覆盖下一条 |
| A12 | 两个舞台就绪申请，一个控制台发送伪确认 | 唯一 owner；预览舞台静音；非 owner 与旧确认不推进状态 |
| A13 | 断开 owner、丢失心跳、模拟慢连接 | 当前发言取消；不继续付费生成；其他客户端不被拖住；新 owner 明确申请后可处理新发言 |
| A14 | 不发送 started 或 ended，推进相应超时 | 一次失败、取消当前、释放播放权；重新就绪后恢复，无永久 waiting |
| A15 | 服务重启后返回新 instance_id，旧客户端发送确认 | 忽略旧实例；清空前端旧音频；新快照不重放历史 |
| A16 | 真模式配置缺失或值非法 | 启动明确失败，仅显示字段名；不静默进入演示模式 |
| A17 | 替身返回无效 JSON、超长台词、未知动作、超时或错误 | 文本错误按协议失败并退避；未知表现回退；无无限重试；下一条可继续 |
| A18 | TTS 替身失败或产物超过大小上限 | 明确 error、降级为字幕；不记作语音成功；无残留临时文件累积 |
| A19 | 多轮运行并推进清理时钟 | 记忆最多 20 回合；去重与音频受上限约束；当前音频不被清理 |
| A20 | 外域 Origin、非法 Host、路径穿越、尝试读取 .env | 按边界拒绝或 404；不泄露文件与配置；合法同源请求仍可用 |

阶段 1A 浏览器实测：控制台可开始、暂停、恢复、跳过和发送弹幕；舞台在字幕模式展示并确认；关闭舞台立即停止本地播放逻辑。确认错误和模式文字可见、文字不会越界，且浏览器控制台无未处理错误。截图、报告和录屏放入忽略的 `artifacts/` 等目录。

## 阶段 1B 真实 LLM 与语音

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| B01 | demo + edge，舞台启用声音并开始 | 至少连续 3 条真实可听语音；字幕一致；没有重叠；记录音色、设备和浏览器 |
| B02 | 清除音频就绪状态或模拟 play() 拒绝 | 显示启用入口；报告 autoplay_blocked；不提前发送 ended，不持续消耗模型调用 |
| B03 | openai + edge，发送 3 条不同弹幕并等待 2 次自主发言 | 真实返回通过校验，回答对应观众输入；记录模型、实际请求数、成功/失败与耗时，不记录密钥 |
| B04 | 语音播放中暂停或关闭舞台 | 已连接舞台收到取消后 1 秒内停止声音；关闭舞台本地立即停止；恢复不重播旧内容 |
| B05 | 断网或让真实供应商不可用 | 错误清晰；模式不伪装成功；超时结束；网络恢复后新消息可继续处理 |
| B06 | 本地小鲸固定声线 | 使用获认可且校验通过的参考；连续生成、实际 playing/ended；合成时取消可终止工作进程、删除临时文件，下一条可恢复；公开状态不泄露本地路径 |

B03 分别记录“后端接收到 ready”和“后端接收到 started”的耗时，至少列出样本数、最大值与失败数；不把 OBS 或平台推流延迟混入后端延迟。首轮采集基线后再决定性能优化目标，不预先声称固定低延迟。

- C01：记录 Core、PixiJS、插件、模型及浏览器的准确版本；模型、纹理和运行库本地加载成功，无外部 CDN 请求。

## 阶段 3 B站

- D01：记录所用官方接入能力、应用资格、消息权限及已授权主播，不记录密钥与身份码。缺少权限时标为待外部条件。
