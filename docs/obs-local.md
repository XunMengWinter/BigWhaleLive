# 当前 Mac＋OBS 本地采集

本指南对应最初用户授权的本地采集。使用独立 `BigWhaleLocal` 配置与场景集合，1080×1920、30 FPS；只采集大肥鱼舞台及其声音。已有直播实例时，不在该实例切换配置、场景或音频设备。用户随后明确授权正式接管，现已使用独立 `BigWhaleLive` 推流；当前操作和重启见 [正式直播](live-operation.md)。不要在正式8766服务运行时同时启动本地测试。

## 启动

已有本地环境、模型和私有 `.env` 时，在项目目录执行：

```bash
./tools/start_local_capture.command
```

也可双击该文件。它保持前台终端运行，关闭终端或按 Ctrl+C 停止服务；不安装开机自启。默认是独立 8766 服务，初始暂停，弹幕关闭，模型和固定声线沿用本项目配置。8765 主服务不受此启动器控制。

- [本地控制台](http://127.0.0.1:8766/control)：开始、暂停、恢复及发送模拟弹幕。
- [普通预览](http://127.0.0.1:8766/)：保留手动声音入口，OBS 持有播放权时保持静音。
- OBS 来源：`http://127.0.0.1:8766/?view=obs&audio=auto`。此参数显式请求启用声音，不自动开始主播、不抢占其他播放者。浏览器拒绝自动播放时，使用来源「交互」点击启用声音。

若本地采集也要读取固定房间 9748572，在停止当前 8766 服务后执行：

```bash
./tools/start_local_capture.command --with-danmaku
```

这会沿用 `.env` 的 `BILI_MODE=web` 访客配置，仍不登录账号、不读取登录 Cookie。此时在控制台开始主播，只向本地 OBS 输出声音；这条命令不设置推流地址、不开始直播。默认测试服务没有开启 B站读取，避免与现有 8765 重复连接和回复。

## OBS 配置

本机已安装 OBS 33.0.1，独立配置与集合均为 `BigWhaleLocal`，其中场景为「大肥鱼·本地采集」，唯一来源为「大肥鱼·竖屏与声音」。后续正常使用时，在无活动输出的 OBS 实例中选择这两个名称。

在另一台 Mac 首次安装，或关闭本项目测试 OBS 后需要重建本项目配置时，执行：

```bash
.venv/bin/python tools/obs_local.py prepare --install
```

工具只安装自己的配置；同名配置存在且无项目所有权标记时拒绝覆盖。不要在 `BigWhaleLocal` 实例运行期间重建文件。它不复制已有推流服务、登录资料或其他场景，不更改全局 WebSocket 设置。macOS 多实例仍共享部分 OBS 全局偏好，不能视为完整沙箱；多开仅供隔离本地测试。

配置要点：

- 基础及输出画布均为 1080×1920、30 FPS；单个浏览器来源同尺寸。
- 录制使用本机可用的 Apple H.264 硬件编码器；不适用于没有该编码器的平台。
- 「通过 OBS 控制音频」开启，音频监控关闭，录制只用第 1 音轨。桌面音频及麦克风均未添加，避免重复采集或将本地声音输出到桌面。
- 录制为 MKV，保存到项目 `artifacts/obs-recordings/`；生成音频在 `runtime/obs/audio/`。二者均被 Git 忽略。
- 服务初始暂停；确认 OBS 来源就绪后，在独立控制台开始主播，再开始本地录制。完成后先暂停主播，再停止录制。
- 本地配置提供 `Ctrl+Option+Shift+F10` 停止录制快捷键；没有设置开始或停止直播快捷键。

官方说明：[浏览器来源](https://obsproject.com/kb/browser-source)、[启动参数](https://obsproject.com/kb/launch-parameters)。本轮自动化使用 `--multi --profile BigWhaleLocal --collection BigWhaleLocal --scene 大肥鱼·本地采集 --startrecording`；没有使用 `--startstreaming`。

## 验收与恢复

先用模拟弹幕验证真实模型、固定声线、字幕和本地成片，再按需要开启访客弹幕。没有就绪播放者时不会继续调用模型。普通预览不应同时发声；检查控制台的播放者状态和 OBS 唯一混音来源。

来源断开后，本条发言取消，不补播旧音频。服务重启后重新检查声音与播放权，再手动开始主播。出现错误先暂停，检查控制台明确错误；不要用第二个有声浏览器代替 OBS 继续运行。若声音被阻止，通过 OBS 来源交互启用；若画面停帧，角色恢复机制会有界重载，也可手动刷新来源。

本地真实录制证据见 [当前状态](status.md)。短录制不代表 E02 的 30 分钟稳定性或 E03 的公开推流验收。
